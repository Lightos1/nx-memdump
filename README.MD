# NX Memdump

Dump various mmio regions and sysmodule heaps
Consider this as the successor of https://github.com/Lightos1/emc_dumper

This software is provided "AS IS" and may behave in unexpected ways. <br>
Use it where it helps, but no guarantees, safety or anything is provided in any way whatsoever. <br>
Many of the memory regions cannot be dumped or are potentially complete bs in this context. <br>
Still they're included *for the sake of completeness* <br>
For more details, check TRM, Chapter 2.1, "System Address Map" <br> <br>
Use at your own risk. If you didn't understand what this tool is about, this is not for you. <br>
